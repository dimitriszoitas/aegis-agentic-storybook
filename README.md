# Aegis Agentic Storybook

[Open Storybook](https://dimitriszoitas.github.io/aegis-agentic-storybook/)

This repository contains the compiled public documentation and interactive demos. Development source is maintained separately. The site includes conventional components and patterns, contracts, agent skills and MCP setup documentation; it does not host infrastructure services or an MCP server.

Published source commit: `0d7a9746634b0b1d59f336f97640fac79793714a`. See `aegis-storybook-deployment.json` for build identity. GitHub Pages serves the `main` branch from the repository root. Updates are published by the source repository's explicit publishing command after a project-subpath browser check.
